# Calculadora Básca

Esse é um projeto básico mas que ensina varias maneiras de como fazer, tem adição, subtração, multiplicação, divisão.

## 🚀 Funcionalidades
O pograma permite 4 operações fundamentais
- **Adição (+)**
- **Subtração (-)**
- **Multiplicação (x)**
- **Divisão (/)**

## 🛠️ Tecnologias Utilizadas
- **Scanner**: Para obter a entrada de dados do usuário.
- **Printf**: Para formatar o resultado com uma casa decimal.
- **Switch**: Usei essa função para deixar o codigo mais limpo e queria usar algo diferente do if elif.

## 📝 Observações
- O codigo usa Scanner.nextLine(); após o nextDouble(); para limpar o buffer do teclado, evitando que leitura do NextLine(); seja pulado.
- Os resultados foram formatados em %.1f. Oferecendo um resultado mais limpo e direto.
